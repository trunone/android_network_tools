# Android Network Tools

A simple Android application providing various network diagnostic tools.

## Features

- **Local Network Information:** View detailed information about your device's network interfaces, IP addresses, and gateway.
- **Ping:** Test the reachability of a host on an Internet Protocol (IP) network with customizable count and timeout.
- **Traceroute:** Trace the path packets take to a destination host with configurable max hops and timeout.
- **ARP Table:** View the Address Resolution Protocol (ARP) table to see mapping between IP addresses and MAC addresses.
- **DNS Lookup:** Query DNS records to resolve hostnames to IP addresses.
- **Port Scanner:** Scan TCP ports on a target host within a configurable range and timeout.
- **Subnet Calculator:** Calculate network address, broadcast address, netmask, wildcard mask, and usable host IP ranges for IPv4 subnets.
- **Wake-on-LAN:** Send magic packets to remotely wake up devices on the local network.

## Tech Stack

- **Language:** Java
- **UI Framework:** Android Material Design 3
- **Build System:** Gradle
